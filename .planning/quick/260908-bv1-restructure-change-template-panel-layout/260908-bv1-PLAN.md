<objective>
Restructure the storefront editor's "Change template" panel so the merchant's currently-published template renders in its own spotlighted card above the switchable grid, matching the Shopify "Online Store" layout the user referenced — instead of today's inert-in-place card sitting inside the same grid as every other tile.

Purpose: quick task 260908-bv1 (CONTEXT.md D-A, D-B). Phase 5.1's redesign (05.1-06) shipped the current template as a large, disabled card among selectable ones — visually redundant and, per the user's own words, less professional than a dedicated "here is what you have" moment above the switch grid. This is a pure client-rendering restructuring of data the RSC already assembles; no schema change, no new dependency, no change to `switchTemplate`'s authorization boundary.

Output: two new shared components (`TemplateMedia`, `CurrentTemplateCard`), a filtered call site in `ChangeTemplatePanel`, two new string keys, and an extended (not weakened) `template-picker-contract.test.ts`.
</objective>
