# recent.design — Ecommerce Category References

Research pass against recent.design (`recent.design/websites`, filtered to the **Ecommerce** category tag) to inform what a **more advanced storefront tier** could look like for EINORT-Commerce — a higher/premium merchant plan distinct from the baseline template tier. This source skews toward more visually ambitious, motion-heavy, "portfolio quality" commerce sites than either the Framer marketplace pass (`FRAMER-TEMPLATE-REFERENCES.md`) or the Awwwards pass (`AWWWARDS-REFERENCES.md`), both of which already closed the grocery/food and furniture/home gaps, leaving general retail as the thin segment.

## Screenshot status

**Not attempted this session** — screenshots have been confirmed broken across every prior session on this task (Framer pass, Awwwards pass, and the session that established the working technique for this site), consistently failing with "the Browser pane is not displayed, so the page is not compositing frames." No further attempts were made. Every finding below is derived from `get_page_text`, `read_page` (accessibility tree), and targeted DOM extraction via `javascript_tool`. No color, imagery, or other purely visual claim is made anywhere in this document unless it is a direct quote of recent.design's own metadata tags (e.g. "Black & White," "Dark," "Gradient") or a merchant's own on-page copy — those are reported as the source's own labels, not as something this session visually verified.

## Live-URL availability

**9/9 (100%).** Unlike the Awwwards pass (which required visiting each `/sites/{slug}` project page, then hunting for a separate outbound link), recent.design's **listing cards themselves** carry a second link directly to the live external site — no need to visit the `/i/{slug}` post page first to find it, though the post pages were visited anyway for their tag metadata (see below). Of the 9 live URLs, **8/9 were actually open and navigable**; 1 (Basic Geometry) resolved to a password gate (`basic.site/password`), so its structure below is reconstructed from recent.design's own tag/description metadata only, not live inspection.

## Coverage note: only 9 entries exist under "Ecommerce," not 12–15

The task's working technique assumed pagination/infinite-scroll would surface 12–15+ entries. This session confirmed, via repeated `key:End`, `scrollBy`, resizing the viewport to 1280×3000, and direct DOM inspection (`document.body.scrollHeight` stayed exactly equal to the viewport height, `window.scrollY` never moved past 0, no additional `<article>` nodes ever appeared) that **the Ecommerce filter currently returns exactly 9 items, full stop** — there is no hidden second page or lazy-loaded batch beyond what loads on first filter-click. This is consistent with recent.design's own framing as a *daily curation* rather than an exhaustive archive: niche category filters can simply be thin at a given point in time. All 9 available entries were processed in full (rather than stopping short of a target that wasn't achievable), including their `recent.design` post-page metadata (impressions, tags: Style/Color/Interaction/Framework/Technology) and, for the 8 open ones, the live site itself.

Two of the 9 are **Shopify Editions** showcase pages (Winter '26 and Spring '26) — Shopify's own platform-capability showcases, not individual merchant storefronts, exactly as flagged in the task brief. They are included and processed but classified separately, leaving **7 genuine individual-merchant sites**.

## 1. Shopify Editions (Winter '26)

- recent.design post: https://recent.design/i/kj4b7fu-shopify-editions
- Live site: https://www.shopify.com/editions/winter2026
- Classification: **Shopify platform showcase, not a merchant storefront**
- recent.design tags: Category Ecommerce · Style: Typographic, Big Background Image, Editorial · Interaction: Scrolling Animation · Framework: React, React Router · Platform: Cart Functionality · Hosting: Cloudflare · Styling: Tailwind CSS · Technology: **Lenis, Three.js, Theatre.js**
- Section structure: themed edition title ("The Renaissance Edition," "A new world of commerce, 150+ product updates") → 12 feature-category chapters navigated via a persistent nav rail (Sidekick/AI, Agentic, Online, Retail, Marketing, Checkout, Operations, Shop app, B2B, Finance, Shipping, Developer), each chapter a scroll-driven section describing a cluster of platform features.
- Advanced-vs-baseline: **advanced-tier reference only, not buildable as a merchant template.** The stack (Three.js + Theatre.js for keyframed 3D/timeline animation, Lenis for inertial smooth-scroll) is a full cinematic scrollytelling build, appropriate for a platform's own flagship marketing page, wildly disproportionate for a merchant storefront template. Its real value to EINORT is as a **technology-and-ambition ceiling reference**: this is roughly the top of what "advanced tier" could aspire toward for a single hero/landing section, not a pattern to reproduce wholesale.

## 2. Silo

- recent.design post: https://recent.design/i/chfdsc3-silo
- Live site: https://www.silosilosilo.com/
- Best-fit segment: **no clean fit** (single-SKU modular hardware/EDC accessory — closest to general retail as a niche housewares/gadget-accessory brand, or could be read as an electronics-adjacent precision-hardware product)
- recent.design tags: Style: Typographic, Geometric, Minimal, Clean, Illustrative, Interactive, Big Background Video · Color: Black & White, Muted · Platform: Cart Functionality, Webflow · Library: GSAP · Technology: Lenis, Swiper, jQuery
- Section structure (confirmed live): this is **not a traditional multi-section storefront at all** — it is a single-page interactive product configurator. A "LID" module selector (15/30/60/90mm sizes) sits above material/insert options (Titanium 15mm Insert, Aluminum 30mm/60mm Insert, Cap), each with its own price and a running quantity/total that updates live as options are toggled, ending in a single "Checkout" action. No category grid, no separate PDP navigation — build-your-own-product **is** the homepage.
- Advanced-vs-baseline: **advanced-tier-only.** A live-updating, multi-variant, price-computing configurator (GSAP-driven, video-backed) is a genuinely different engineering problem from a product-card grid — it needs a stateful assembly/pricing model, not just a CMS content block. This is the single clearest "build vs. buy" line in this entire research pass: a config-driven catalog/grid system (baseline) cannot produce this experience without a dedicated configurator component built specifically for it.

## 3. Fidèle (Fidèle Éditions)

- recent.design post: https://recent.design/i/ukagqeu-fidele
- Live site: https://fidele-editions.com/
- Best-fit segment: **general retail** (closest genuine multi-category candidate found across all three reference passes — see synthesis below) — a Paris publishing house / Riso print studio selling books, art prints, and a clothing/objects sub-line
- recent.design tags: Style: Typographic, Playful, Large Type, Editorial · Color: Gradient, Muted (site is 5 years old per recent.design's own "5y ago" timestamp — long-lived, not a flash-in-the-pan build)
- Section structure (confirmed live): free-shipping announcement bar → "What's on: Latest" product grid, each item author/artist-attributed with EUR pricing (books, a puzzle, a tee-shirt, a pouch bag) → short editorial mission statement + link into full shop catalog → distribution/wholesale note (names an external distributor, B2B contact email) → a full **content-as-commerce interstitial**: an artist interview tied to a specific release ("Zéphir: Interview") → studio-operations news block (announcing they've stopped taking outside print clients) → sub-brand introduction block ("Fidèle PrintWorks™" — the clothing/objects line, with its own wholesale contact) → second curated product grid ("Confidens Series," grouped by book collection) → press-mention block (an Asian-tour magazine feature).
- Advanced-vs-baseline: **mostly baseline-achievable**, and notable for that reason — nothing here needs custom animation or 3D; the sophistication is entirely in **content structure**: interleaving genuine editorial content (interviews, studio news, press mentions) with commerce sections as one continuous "latest from the studio" stream, rather than silo-ing blog and shop into separate site areas. That IA pattern — commerce feed and content feed unified — is achievable at baseline tier as a config-driven "mixed feed" block type, and is one of the more exportable ideas from this whole pass regardless of tier.

## 4. Bécane Paris

- recent.design post: https://recent.design/i/1s74lok-becane-paris
- Live site: https://www.becaneparis.com/
- Best-fit segment: **fashion/apparel** (technical/protective womenswear, motorcycle-culture positioning — "Bécane" is French slang for motorbike)
- recent.design tags: Style: Typographic, Minimal, Clean, Editorial · Interaction: Scrolling Animation · Framework: React, Next.js · Hosting: Vercel · Library: Motion · Technology: **Three.js, PWA**
- Section structure (confirmed live): the entire homepage is a single hero-scale brand statement — a live product/story counter in the header ("All 27 / Stories 04 / Cart 00"), a single active capsule collection framed as "Collection 01/01" with one named drop ("Heroines Drop," 14 products, one "Discover" CTA into a dedicated look/collection page), a one-paragraph brand-manifesto line ("Born on the road, made for the city... unapologetically feminine"), and a footer of policy links + contact. A separate "/story/{slug}" route (confirmed via DOM: "Lou Escobar Bécane Paris") indicates a dedicated editorial/ambassador-story content type sitting alongside the product catalog, not merged into it.
- Advanced-vs-baseline: **hybrid.** The single-collection, counter-driven homepage IA (product count / story count / cart count as the entire above-the-fold navigation) is a distinctive, buildable-at-baseline content decision — it's a data/config choice (show N active items, not a generic mega-grid), not a code-complexity one. What pushes it to advanced-tier is the *execution*: Three.js-backed visuals and Motion-library-driven scroll transitions turning a fairly sparse content set into a cinematic single-page experience — the same "thin content, rich motion" trade visible in Silo and both Shopify Editions entries.

## 5. Vitra: Office Chair Finder

- recent.design post: https://recent.design/i/426udpb-vitra-office-chair-finder
- Live site: https://findmy.vitra.com/en-en/questionnaire/chairs
- Best-fit segment: **furniture/home** (office seating)
- recent.design tags: Style: Minimal, Clean, Interactive · Color: Muted · Interaction: Transitions · Framework: React, Next.js · Hosting: Vercel
- Section structure (confirmed live): not a storefront homepage at all but a **standalone guided-discovery tool** — a multi-step questionnaire (recent.design's own description: sliders for desired height, sitting time, breathability, and padding preference) that narrows Vitra's full chair catalog down to a filtered results grid (confirmed live: 25+ chair models — Soft Pad, HAL, ID Mesh, Aluminium Chair EA-series, etc. — rendered as a plain image grid once the quiz completes), with a "go back" affordance to revise answers.
- Advanced-vs-baseline: **the underlying pattern is buildable at baseline, the execution polish is advanced.** A slider/preference-driven quiz that filters a product catalog by structured attributes (height range, use-case tags, material tags) is fundamentally a config-driven wizard over existing product metadata — well within reach of a template-recombination system, *if* the product data model has the right attribute fields to filter on. What's advanced-tier is the transition polish and the standalone-microsite treatment (its own subdomain, its own minimal chrome) rather than being bolted on as a widget inside the main storefront nav. Directly reinforces the Awwwards pass's furniture/home finding that multi-axis, guided navigation is the segment's signature move — this is the most sophisticated version of it seen across all three passes.

## Synthesis

### (a) Updated segment-coverage picture across all three reference passes

- **Furniture/home** — already closed by the Awwwards pass (4 references: Ferm Living, Case Furniture, Skanvi, Great Dane Furniture). This pass **adds 3 more** (Vitra Office Chair Finder, Basic Geometry, Resident), all reinforcing rather than changing the picture — specifically doubling down on **designer/maker attribution** (Resident) and **guided multi-attribute product-finder tools** (Vitra) as the segment's two signature moves, now confirmed across 7 total furniture references spanning three independent sources. Solidly closed.
- **Fashion/apparel** — already over-represented across both prior passes. This pass adds 2 more (Bécane Paris, Icebug), both consistent with, not extending, the existing picture. Bécane's single-collection/drop-counter homepage IA and Icebug's plain, fully-baseline-buildable multi-category structure are useful as two ends of the same segment's tier spectrum (advanced single-drop editorial vs. baseline full-catalog retailer) but don't change the segment's status.
- **Beauty/cosmetics, electronics, grocery/food** — no new candidates surfaced in this pass (recent.design's 9-item Ecommerce set simply didn't contain any). Status unchanged from the Awwwards pass: all adequately covered/closed.
- **General retail — still the thinnest segment, marginally but not decisively improved.** Fidèle is the best "general retail" candidate found across *all three* reference passes to date: it's the only site in any pass that genuinely sells across unrelated product categories (books, art prints, apparel, objects) from one storefront rather than a single vertical. It's a real, live, non-bespoke, non-campaign-microsite example — a meaningfully better data point than the Awwwards pass's single general-retail candidate (Decathlon Yestalgia, which turned out to be a bespoke campaign microsite, not usable). However, Fidèle is still a *niche* multi-category retailer (an independent publisher/print studio with a small side line of merch), not the "generalist household/variety store" shape that a broad swath of Cameroon SME merchants running general retail would actually resemble. **Verdict: general retail's gap is narrower but not closed** — Fidèle's content-plus-commerce IA pattern is worth borrowing, but a follow-up pass specifically targeting broad-catalog, many-unrelated-category general stores (variety stores, "everything shop" DTC brands, marketplace-style single-vendor stores) would still be worthwhile if this gap needs to be fully closed before V1 template design locks.

### (b) Advanced-tier vs. baseline-tier patterns — the core deliverable of this pass

**Reserve for a higher/advanced merchant tier** (all require either bespoke engineering investment per-template or meaningfully higher asset/production cost per merchant, not just a config toggle):

1. **Live interactive product configurators** (Silo) — stateful multi-variant assembly with real-time price computation and visual updates. This is a distinct component class, not a catalog-grid variant; building it once as a reusable "configurator" block would still only pay off for merchants with genuinely modular/build-your-own product lines.
2. **Custom 3D/WebGL product rendering synced to scroll or interaction** (Basic Geometry's animated 3D renders, both Shopify Editions entries' Three.js scenes) — requires a 3D asset pipeline per product/hero, not just better photography; the production cost per merchant is the real gate here, not just the code.
3. **Cinematic scroll-choreography stacks** (Lenis smooth-scroll + Theatre.js timeline animation + GSAP, seen across Shopify Editions ×2, Silo, Bécane Paris) — a specific, repeatable, but non-trivial technology combination distinct from simple CSS scroll-reveals; worth productizing as an opt-in "cinematic hero" module reserved for the advanced tier rather than baked into every template.
4. **Dedicated guided-discovery microsites** (Vitra Office Chair Finder as its own subdomain/experience, vs. Icebug's version of the same idea as a plain text link) — the *underlying logic* (slider quiz → filtered catalog results) is baseline-buildable as a config-driven wizard over structured product attributes; what makes Vitra's version advanced-tier is the standalone-experience polish and transition design layered on top, not the filtering logic itself. This is worth splitting explicitly: ship the wizard logic at baseline, reserve the immersive standalone presentation for advanced tier.
5. **Kinetic/animated typography as a hero treatment** (per-character animated headline spans on Shopify Editions Spring '26, Framer pass's "Morph Text" component on Altura) — a named, recurring pattern across two independent research passes now, consistently associated with higher-production-value builds.

**Achievable at any tier, including baseline** (structural/content/IA decisions, not engineering-complexity gated):

1. **Clean category-grid catalog with variant/sale badges directly on cards** (Icebug) — the standard, fully reproducible commerce grid.
2. **Universal designer/maker attribution as a product-schema field** (Resident, reinforcing Case Furniture from the Awwwards pass) — zero complexity beyond adding the field and always rendering it; a strong prestige signal for craft-forward segments (furniture, beauty, food) at no engineering cost.
3. **Unified content-and-commerce feed** (Fidèle, Resident) — editorial/story content interleaved with product releases as one stream rather than a separate walled-off blog section. Buildable as a config-driven "mixed feed" block type; the sophistication is entirely in information architecture, not code complexity.
4. **Single-collection/single-drop homepage IA** (Bécane Paris's "Collection 01/01" counter-driven header) — a content/data decision (show N curated items, not a sprawling mega-grid), fully achievable by simply configuring a template to spotlight one collection rather than requiring a distinct "drop" component.
5. **Filtered-results product finder as a plain link/widget** (Icebug's lightweight "Shoe Finder" cross-link, functionally the same underlying logic as Vitra's showcase version) — proof that the *pattern* of guided discovery doesn't require the *production values* of a dedicated microsite to deliver real value.
6. **Sustainability/brand-values statement blocks and wholesale/B2B contact blocks** (Icebug, Fidèle) — plain content sections, no engineering dependency, directly reusable across segments and consistent with prior passes' findings on physical-retail/B2B trust signals mattering for Cameroon's likely hybrid online/physical merchant base.

### (c) Is general retail's gap any closer to closed?

**Narrower, not closed.** Fidèle is a genuine, live, non-bespoke multi-category storefront — the first credible general-retail data point across all three passes (replacing the Awwwards pass's Decathlon Yestalgia, which had to be discarded as a bespoke campaign microsite). But Fidèle's "multi-category" is still narrow and identity-driven (an independent publisher's books + prints + small merch line), not the broader, less-curated "variety/general store" shape that V1's general-retail segment likely needs to represent. If general retail needs to be fully locked before template design work starts, a targeted follow-up pass (searching specifically for "general store," "variety store," "multi-brand DTC," or "everything shop" — rather than relying on curated design-inspiration sites, which structurally favor narrow, tightly-branded single-vertical stores over broad generalist catalogs) is still worth doing.
