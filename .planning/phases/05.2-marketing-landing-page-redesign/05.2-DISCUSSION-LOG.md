## Language for the page

| Option | Description | Selected |
|--------|-------------|----------|
| English for now, matching the rest of the product | Consistent with the English-only dashboard/onboarding/storefront | ✓ |
| French-first, since Douala is majority-Francophone | Better first impression for most real prospective merchants, but inconsistent with the rest of the product | |
| Bilingual toggle (EN/FR) on this page only | Best of both, but adds real scope (translation, switcher) this phase didn't otherwise need | |

**User's choice:** English for now, matching the rest of the product (Recommended)
**Notes:** Confirmed via codebase check: no French strings or locale/language infrastructure exist anywhere in the product today.
