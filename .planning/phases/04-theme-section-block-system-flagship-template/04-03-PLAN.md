<objective>
Add EDIT-03's editor capability gate to the entitlements layer — and defuse the D-15 trap that 04-RESEARCH.md found by reading `resolve.ts` directly.

Purpose: `resolveEntitlements` computes `plan` from `org.planTier` alone; trial state currently touches **only** `canWrite`. The obvious gate — `can(ctx, "storefrontEditor")` — would give a Starter merchant on day 2 of their 10-day trial a view-only editor, a direct violation of D-15. This plan makes the editor boolean trial-aware in the one pure function that knows trial state, and pins that behaviour with unit tests before any editor surface exists to hide it.

Output: `PlanLimits.storefrontEditor`, `MerchantContext.canEditStorefront`, `EditorLockedError`, `assertCanEditStorefront`, and the D-15 cases in `tests/unit/entitlements.test.ts`.
</objective>
