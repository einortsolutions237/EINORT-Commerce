<objective>
Build the editor's four rail and bar components as props-driven client islands, ahead of the shell that owns their state.

Purpose: interface-first. Plan 04-15 assembles `editor-shell.tsx` around a `useReducer`; if these four were written at the same time, the shell would grow their logic and EDIT-02's reorder behaviour would end up in a component that this repo's `node`-only Vitest cannot test. Declaring their prop contracts here forces every state transition through `editorReducer` (plan 04-02) where it already has coverage, and leaves the shell as pure wiring.

Output: `section-list.tsx`, `field-renderer.tsx`, `settings-panel.tsx`, `publish-bar.tsx`.
</objective>
