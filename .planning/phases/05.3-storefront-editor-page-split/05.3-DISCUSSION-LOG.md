## Page structure

| Option | Description | Selected |
|--------|-------------|----------|
| Split into two separate pages | A dedicated "Themes" page separate from a dedicated full-screen "Editor" page — matches Shopify's actual navigation and the user's reference screenshot most closely | ✓ |
| One screen, restructured layout only | Keep template-switching and section-editing on the same screen/route, restyle toward a persistent sidebar + top toolbar feel | |

**User's choice:** Split into two separate pages (Recommended)
**Notes:** None beyond the selection.

## Scope of new capability

| Option | Description | Selected |

| Add Header/Template/Footer grouping | Group the section list the way Shopify does | |
| Add section add/remove | Reverse D-05's locked scope cut — a real feature addition | |
| Add undo/redo | Build undo/redo from scratch — no existing hook point | |

**User's choice:** Layout/structure only (Recommended). User's own words: "In the future all this new capabilities will be added but for now let's go with... Layout/structure only."
**Notes:** All three additional-capability options were explicitly deferred to a future phase, not rejected outright.
