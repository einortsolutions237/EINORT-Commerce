## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer -> repository | Untrusted-by-drift: a future task can silently import the unscoped Prisma client and break TEN-02. The lint zone is the boundary control. |
| npm registry -> node_modules | Supply-chain surface. RESEARCH.md `## Package Legitimacy Audit` is the gate. |
| deploy env -> runtime config | A missing/blank `NEXT_PUBLIC_ROOT_DOMAIN` silently makes every host classify as root, disabling tenant routing. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | Any feature module importing `server/db/base` or `@/generated/prisma` directly | mitigate | `no-restricted-imports` zones in `eslint.config.mjs`, wired into `npm run lint` and asserted by a live probe-file check in Task 3 acceptance criteria |
| T-01-02 | Tampering | `$queryRaw` / `$executeRaw` bypassing the tenant extension (empirically confirmed NOT intercepted) | mitigate | `no-restricted-syntax` ban on `$queryRaw`/`$executeRaw` member expressions across `src/**` |
| T-01-03 | Denial of service | Blank `NEXT_PUBLIC_ROOT_DOMAIN` collapsing all hostnames to `root`, taking every tenant storefront offline | mitigate | `@t3-oss/env-nextjs` boot-time validation with `emptyStringAsUndefined: true`; explicit `runtimeEnv` literal references |
