## Phase Goal

Merchants outside the fashion segment get their own structurally distinct storefront, and the template library reaches 50 visually distinct variations (10 Starter / 15 Business / 25 Professional) that a stranger would not mistake for one another.

> Planner note: the ROADMAP `**Goal:**` line for Phase 5 is not in `As a … I want to … so that …` form. It is reproduced verbatim rather than invented. Run `/gsd mvp-phase 5` if the user-story framing is wanted.

<objective>
Split the copy catalogue into a directory so ~1,250 new template strings do not make a 1,731-line file unreviewable, create the six per-segment copy namespaces the authoring plans fill, and land every piece of Phase-5 chrome copy in one place.

Purpose: `05-RESEARCH.md` Pitfall 7 establishes that appending this phase's copy to `src/lib/strings.ts` takes it past 3,000 lines and effectively unreviewable, and that `@/lib/strings` resolves identically to `src/lib/strings/index.ts` so no call site changes. Its warning sign is a move commit that shows content changes — this plan makes the move verbatim and adds copy only afterwards, in separate, reviewable commits.
Output: the directory split, six segment namespaces, all Phase-5 UI copy, and the reconciled Starter template count.
</objective>
