## Phase Goal

Merchants outside the fashion segment get their own structurally distinct storefront, and the template library reaches 50 visually distinct variations (10 Starter / 15 Business / 25 Professional) that a stranger would not mistake for one another.

> Planner note: the ROADMAP `**Goal:**` line for Phase 5 is not in `As a … I want to … so that …` form. It is reproduced verbatim rather than invented. Run `/gsd mvp-phase 5` if the user-story framing is wanted.

<objective>
Run the phase gate: every automated check, then the two human layers of the distinctiveness gate that no automated proxy can substitute for.

Purpose: TMPL-05 makes genericness a failure condition rather than a subjective nice-to-have, and the only instrument for "would a stranger think these are the same product" is a stranger. `05-RESEARCH.md` scales Phase 4's two-store check to N=50 in three layers; layer 1 shipped in plan 05-20, and this plan runs layers 2 and 3. D-14 folds Phase 4's own still-open Wave 7 Task 3 into this gate, because the flagship is one of the 50 rows and will appear in at least one adversarial pair — so the human check is performed once rather than twice.
Output: the contact-sheet generator, two blocking human verifications, and the STATE.md closure record.
</objective>
