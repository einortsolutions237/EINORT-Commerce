## Phase Goal

Merchants outside the fashion segment get their own structurally distinct storefront, and the template library reaches 50 visually distinct variations (10 Starter / 15 Business / 25 Professional) that a stranger would not mistake for one another.

> Planner note: the ROADMAP `**Goal:**` line for Phase 5 is not in `As a … I want to … so that …` form. It is reproduced verbatim rather than invented. Run `/gsd mvp-phase 5` if the user-story framing is wanted.

<objective>
Make the 10/15/25 split a real server-enforced entitlement gate — a boolean for rendering, a throw for writes — that is deliberately NOT elevated by the trial.

Purpose: D-06 requires the split be a real gate, not a catalog-size description. D-12 and `05-RESEARCH.md` Finding 6 establish the asymmetry with Phase 4's D-15: the editor grant is reversible at trial expiry (the merchant loses edit access, storefront unchanged), a template grant is not — un-granting one would require force-migrating a live storefront, which `registry.ts`'s own header calls permanently banned. Pitfall 6 names the failure this plan exists to prevent: a picker that filters correctly so manual testing passes, while a direct POST with an out-of-tier key succeeds.
Output: the tier rank table, the registered catalog size, the domain error, and the boolean/throw access pair.
</objective>
