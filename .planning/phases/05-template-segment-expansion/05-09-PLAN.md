## Phase Goal

Merchants outside the fashion segment get their own structurally distinct storefront, and the template library reaches 50 visually distinct variations (10 Starter / 15 Business / 25 Professional) that a stranger would not mistake for one another.

> Planner note: the ROADMAP `**Goal:**` line for Phase 5 is not in `As a … I want to … so that …` form. It is reproduced verbatim rather than invented. Run `/gsd mvp-phase 5` if the user-story framing is wanted.

<objective>
Build the two presentational pieces both template-selection surfaces share: a zero-byte geometric thumbnail that renders from a template's own skeleton, and the picker grid that wraps it.

Purpose: `05-RESEARCH.md` Pattern 6 rejects screenshots because 50 images in R2 or `public/` would create a regeneration obligation on every skeleton change and real bytes on the low-end Android this market runs on. Rendering the thumbnail *from* the skeleton means it cannot drift. Building one picker for both surfaces means the onboarding and editor experiences cannot diverge — 05-UI-SPEC § Editor "Change Template" Action specifies three data-driven differences, not a second component.
Output: `template-thumbnail.tsx` and `template-picker.tsx`, both taking plain data props and importing nothing from `server-only` modules.
</objective>

Props: `readonly sections: readonly TemplateSectionRef[]` and `readonly primaryAccent: string`. Nothing else — no template key, no name, no segment. Name and segment tag render on the card outside the thumbnail frame, per 05-UI-SPEC.

Implement exactly the 05-UI-SPEC contract:

- Frame: `aspect-[3/4] rounded-md border border-border bg-background overflow-hidden`, minimum width 140px.
- Content: a vertically stacked miniature of the section list, each section one flat block sized proportionally to that section's real relative height — hero tallest, trust-bar and contact shortest.
- Per-variant block shapes, all twelve: `hero:full-bleed` one tall filled block · `hero:split` two side-by-side half-width blocks · `hero:stack` a short centred text-only mark of 2-3 thin bars with no fill block · `trust-bar:band` one wide washed block with 3-4 small ticks · `trust-bar:strip` one thin bordered line with small dots · `product-grid:grid` 4 small squares in a row · `product-grid:dense` 5-6 tighter squares · `product-grid:showcase` 2 larger rectangles · `editorial-split:split` one dark block beside a lighter block · `editorial-split:banner` one full-width dark bar · `contact:band` one thin centred bar · `contact:card` a small bordered box centred on a light field.
- Dispatch section-to-shape through an exhaustive `switch` on `section.type` with an inner `switch` on `section.variant`, mirroring the renderer's discipline. A thirteenth variant must be a compile error here, not a blank block.
- Colour: every block is `bg-muted` or `bg-border` (neutral dashboard greys) **except exactly one** — the block representing the template's primary CTA, which is the hero block, or the contact block if a skeleton somehow has no hero. That one block is filled via `style={{ backgroundColor: primaryAccent }}`. `primaryAccent` is validated Zod state arriving as a prop; it must never be a Tailwind palette utility (ban 1) and never a literal colour in the `.tsx` (ban 2).
- No text inside the thumbnail at all — purely geometric. This avoids needing legible micro-copy at 140px across 50 templates and keeps a 25-card grid render-cheap.
- The whole thumbnail is decorative relative to the card's own label, so mark it `aria-hidden="true"`; the card's `Label` carries the accessible name.

Prefer no `"use client"` — this component holds no state and runs no effect, so it should render inside whichever tree its parent is in. Do not import from `@/server/theming/registry` or `@/server/theming/defaults`; both carry `server-only` and `tests/unit/theming-marker-boundary.test.ts` fails the build on it.

Never use `--brand-accent*` tokens or the zinc storefront palette here — this is a surface 2/3 component, and the merchant's own storefront accent reaches it only as the one inline `backgroundColor` value.

  <action>
Create `src/components/theming/template-picker.tsx` exporting `TemplatePicker` and the `TemplateTile` type it consumes. Mark it `"use client"` — it owns selection state and a disclosure toggle.

`TemplateTile` is plain data assembled server-side and handed down: `key`, `name`, `segment`, `segmentTag`, `minTier`, `sections` (the `TemplateSectionRef[]` the thumbnail renders from), `primaryAccent`, and `locked: boolean`. The component must not import `@/server/theming/registry` or `@/server/theming/defaults` — the RSC flattens the registry to plain data, exactly as `/onboarding/branding/page.tsx` already does for `SegmentTile[]`.

Props beyond the tiles: the currently selected key, a change handler, an optional `currentKey` (the merchant's existing template, used by the editor surface), an optional `sortBySegment` value (the merchant's industry, used by the onboarding surface), a `showAllToggle: boolean`, and an optional error message. The three differences 05-UI-SPEC lists between the onboarding and editor surfaces are all expressed through these props — do not fork the component.

Grid and card, per the UI-SPEC:

- `grid grid-cols-2 gap-4 sm:grid-cols-3`, `radio-group` semantics, one required selection, **no pre-selected default** on the onboarding surface.
- Card wrapper `rounded-lg border p-2` with `<TemplateThumbnail>` on top. Unselected `border-border hover:bg-accent`; selected `border-primary ring-2 ring-primary` — the identical selected-state language the industry tile already uses, so the merchant recognises the pattern.
- Card copy below the thumbnail: template display name in the Label role (14/600, `mt-2 px-1`) and the segment tag in Body `text-muted-foreground` (`mt-1 px-1`). Label, not Heading — a 25-card grid of Heading-weight names would compete with the page `h1`.
- Whole tile is the tap target: stretch the radio over the card at zero opacity exactly as the industry tile does. There must be no 16px dot to hit on a phone.
- Tier-locked card (`locked: true`): same thumbnail at `opacity-60`, a centred chip overlay on the thumbnail reading `strings.branding.templateLockedChip(tier)` with a `lock` icon, styled `bg-background border border-border text-foreground` — the exact out-of-stock-tile visual language, reused rather than inventing a badge colour. Radio `disabled`, `aria-disabled="true"`, `cursor-not-allowed`. Tapping does nothing and opens no dialog. A `tooltip` on focus and hover reads `strings.branding.templateLockedTooltip(tier)`.
- Current-template card (`key === currentKey`): `border-primary ring-2 ring-primary` plus a small pill badge top-left of the thumbnail, `bg-primary text-primary-foreground`, reading `strings.editor.templateCurrentBadge`. If it is also `locked`, render the caption `strings.editor.templateRetainedCaption` beneath the card and make the card inert — clicking it must never fire the change handler, because re-selecting it would route a downgraded merchant into the confirm dialog for a template the gate is supposed to prevent.
- Segment sort (onboarding only, when `sortBySegment` is set): templates whose `segment` matches float to the front of the same tier-accessible set. This is a SORT, never a filter — no card is ever removed. A hard filter would make `Organization.industry` mechanically determine the reachable set, which D-05 permanently forbids. Transition with a plain local `transition-opacity duration-200`; do not borrow the storefront's `--motion-quick` token across surfaces.
- Show-all toggle (`showAllToggle: true`): a `text-primary underline` Label link beneath the grid's first row, toggling `strings.branding.templateShowAll(n)` and `strings.branding.templateShowRecommended`, where `n` is the count of tiles passed in.
- Error: when an error message prop is set, render it beneath the grid as `text-destructive`, matching the existing form's error styling.

Every string is a member expression into `@/lib/strings`. Zero user-facing literals — the `.tsx` prose-scanning contract tests fail the build on one. Surface 2/3 tokens only: blue/gold/slate, `font-heading` for headings, 0.75rem radius. Never `--brand-accent*`, never the zinc storefront palette; gold is fully spent and no picker element may use it.
