## Phase Goal

Merchants outside the fashion segment get their own structurally distinct storefront, and the template library reaches 50 visually distinct variations (10 Starter / 15 Business / 25 Professional) that a stranger would not mistake for one another.

> Planner note: the ROADMAP `**Goal:**` line for Phase 5 is not in `As a … I want to … so that …` form. It is reproduced verbatim rather than invented. Run `/gsd mvp-phase 5` if the user-story framing is wanted.

<objective>
Declare all 50 template rows — their segment, their tier, and the ordered section-plus-variant skeleton each renders — and stand up the default-document dispatch that turns a key into a fresh document and token set.

Purpose: D-03 requires each of the 50 to be a real, individually named row in `TEMPLATES` rather than a smaller set of skeletons plus a preset layer. This plan owns the whole allocation in one place so the tier counts, the per-segment Starter coverage and the skeleton reuse cap are decided once and are directly assertable, instead of emerging accidentally from six parallel authoring plans. The six segment modules get their exact function contracts here; plans 05-12 through 05-17 fill them with real design and copy.
Output: 50 registry rows, 25 skeletons, the builder dispatch, and six segment modules with 50 named builder pairs.
</objective>
