## Phase Goal

Merchants outside the fashion segment get their own structurally distinct storefront, and the template library reaches 50 visually distinct variations (10 Starter / 15 Business / 25 Professional) that a stranger would not mistake for one another.

> Planner note: the ROADMAP `**Goal:**` line for Phase 5 is not in `As a … I want to … so that …` form. It is reproduced verbatim rather than invented. Run `/gsd mvp-phase 5` if the user-story framing is wanted.

<objective>
Put the template picker into onboarding as a new Card 3, immediately below the industry tiles, submitted by the same `saveBranding` call — so a merchant leaves onboarding with a real, deliberate template pick.

Purpose: D-07 requires the pick to happen right after industry selection, and `05-RESEARCH.md` Pattern 7 establishes why it belongs inside the existing form rather than at a new `/onboarding/template` route: a separate route needs a "template not yet chosen" state to gate on, `templateKey` carries a DB default so absence is not representable, and the only other signal would require adding a second-table read to `requireMerchantContext`, whose parameter-less single-read shape is pinned by `tests/unit/no-tenant-id-param.test.ts`. Zero new routes, zero new DAL rungs, zero new half-onboarded states.
Output: the server-side tile assembly and the new form card.
</objective>

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-66 | Elevation of Privilege | a locked card treated as the gate | mitigate | `locked` only dims and disables a card; `saveBranding` re-checks `canUseTemplate` against the organization's own `planTier` (plan 05-11) and refuses |
| T-05-67 | Tampering | industry hard-filtering the reachable set | mitigate | The picker sorts, never filters; card count is asserted unchanged across a sort. D-05 permanently forbids industry mechanically determining the pick |
| T-05-68 | Information Disclosure | `server-only` registry pulled into the branding island | mitigate | Tiles assembled in the RSC; `npm run build` and `tests/unit/theming-marker-boundary.test.ts` both gate it |
