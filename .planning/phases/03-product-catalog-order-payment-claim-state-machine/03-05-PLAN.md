## Phase Goal

ROADMAP goal (verbatim): *A merchant can list a product and a customer can complete a full purchase through to a merchant-confirmed order, with stock, order state, and payment-claim integrity guaranteed server-side.*

Derived user story (same derivation 03-01 and 03-02 committed):
**As a** Cameroonian merchant and their customer, **I want to** list products and complete a purchase through WhatsApp, Mobile Money claim, or cash on delivery, **so that** the sale is recorded, the stock is correct, and the payment status is auditable.

**This plan's slice:** a merchant's phone photo becomes a storefront-quality image — uploaded straight to R2, auto-rotated, cropped square and re-encoded, with three derivatives ready to render. This is the CAT-02 pipeline, and D-07 makes it the same pipeline Phase 4's onboarding logo will use.

<objective>
Build the three-step image ingest — mint a presigned PUT, let the browser upload direct to R2, then derive and write back with Sharp in the Node runtime — as a preset registry rather than a one-off.

Purpose: Next 16 caps Server Action bodies at 1 MB, which a phone camera JPEG routinely exceeds, so presigned direct-to-R2 is mandatory rather than preferable. And CAT-02 asks for *enhancement*, not display-time resizing: `next/image` produces no stable stored derivative and cannot fix a badly-exposed merchant photo.
Output: `src/server/images/{r2,pipeline,actions}.ts`, the Node-runtime finalize route, and two unit tests that run with no network.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → R2 (presigned PUT) | The browser holds a time-limited write grant issued by this codebase; whatever the grant permits, the browser can do |
| Browser → finalize Route Handler | An authenticated but otherwise untrusted body naming which upload to process |
| Uploaded bytes → Sharp | Attacker-controlled binary input decoded by a native library |
| Tenant A's presign → tenant B's prefix | Shared bucket; the key layout is the only boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-23 | Elevation | A presigned URL used to write outside the caller's tenant prefix | mitigate | `objectKeyFor(ctx.tenantId, …)` composes the key from the session-resolved tenant and a server-generated uuid; the action schema accepts no key, no path and no filename, and `tests/unit/r2-key.test.ts` proves traversal input throws |
| T-03-24 | Tampering | A signed image URL reused to store a script or an HTML polyglot | mitigate | `ContentType` is pinned in `PutObjectCommand` at signing time (R2 returns 403 on mismatch), the allowlist excludes `image/svg+xml`, and Sharp re-encodes every stored derivative to WebP so the served object is never the uploaded bytes |
| T-03-25 | Denial of service | Decompression bomb (a 100 MP PNG that expands to gigabytes) | mitigate | `sharp(input, { limitInputPixels: 50_000_000 })` plus `maxDuration = 30` on the finalize route plus a 10 MB `byteSize` ceiling in the mint schema |
| T-03-26 | Denial of service | Sharp loaded on the Edge runtime | mitigate | No `runtime = "edge"` anywhere in the import graph; asserted by grep in Tasks 2 and 3 |
| T-03-27 | Information disclosure | A presigned URL or an object key appearing in a log or an error body | mitigate | Error responses carry a code, never the key or the URL; documented in the route header (ASVS V7) |
| T-03-28 | Information disclosure | The unprocessed `original` object being publicly reachable | mitigate | `publicUrlFor` is documented as derivative-only and no code path emits a public URL for a key ending in `/original` |
| T-03-SC | Tampering | npm installs | accept | No installs in this plan; `@aws-sdk/client-s3`, `@aws-sdk/s3-request-presigner` and `sharp` were installed at pinned versions by 03-02 after the RESEARCH.md § Package Legitimacy Audit (4/4 `[OK]`, no postinstall scripts) and a blocking human registry spot-check |
</threat_model>
