## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Server Action / Route Handler → Postgres | Every catalog, order and claim write crosses here carrying values that may originate from an anonymous customer |
| Tenant A's request → Tenant B's rows | Shared-schema multi-tenancy; the only structural guards are `scopedDb` and the composite FKs added here |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering / Elevation | `Product.categoryId`, `ProductVariant.productId`, `OrderItem.orderId` in a create payload | mitigate | Composite FK `@relation(fields: [tenantId, <fk>], references: [tenantId, id])` — a cross-tenant reference is a Postgres rejection, not a code check |
| T-03-02 | Elevation | A new tenant-scoped model omitted from `TENANT_SCOPED_MODELS` | mitigate | `scopedDb` throws on an unregistered model; `tests/isolation/model-registry-drift.test.ts` fails the build |
| T-03-03 | Tampering | Nested Prisma writes bypassing the scope extension | mitigate | `tenantId` required with no default on all nine models makes a nested create a compile error (Pitfall 1) |
| T-03-04 | Spoofing | Reused proof-of-payment reference | mitigate | `@@unique([tenantId, referenceNormalized])` on `PaymentClaim` — an index cannot be raced |
| T-03-05 | Information disclosure | Guessable order-tracking token | mitigate | `Order.trackingTokenHash` stores only a SHA-256 hash under a global unique index; plaintext is never a column |
| T-03-06 | Repudiation | An order state change with no record of who did it | mitigate | `OrderEvent` model with `actor` + `actorUserId`, written in the same transaction by plan 03-03's `transitionOrder()` |
| T-03-07 | Tampering | Multiple all-empty "default" variants each holding separate stock | mitigate | `option1Value`/`option2Value` are `NOT NULL DEFAULT ''`, so the unique index actually collides (Pitfall 2) |
| T-03-SC | Tampering | npm installs | accept | No package installs in this plan. RESEARCH.md § Package Legitimacy Audit covers the five packages installed by plan 03-02 (all `[OK]`, no postinstall scripts) |
</threat_model>
