<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `/api/auth/organization/*` | An authenticated merchant can POST arbitrary JSON at 34 live Better Auth endpoints; create/update bodies are the path a forged `planTier` would take |
| application → database | The only writer of plan/trial columns is server code through `platformDb`; there is no public API path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | `POST /api/auth/organization/create` and `/update` bodies | mitigate | Declare all four columns `input: false` in `auth.ts` `additionalFields`; `toZodSchema({ isClientSide: true })` drops them and Zod strips unknown keys, so the forged value never reaches `ctx.body` |
| T-02-02 | Tampering | Trial expiry state | mitigate | No stored `isExpired` boolean exists; `resolveEntitlements` derives `endsAt` from `organization.createdAt`, which Better Auth's own endpoint spreads last over the request body and is therefore unforgeable |
| T-02-03 | Elevation of Privilege | `memberLimitFor` with an absent or unknown `planTier` | mitigate | Fail closed to 1 (owner only); never return 0, which Better Auth's `membershipLimit \|\| 100` would silently widen to 100 |
| T-02-04 | Information Disclosure | Entitlement modules importing the generated Prisma client outside the lint sanctuary | mitigate | `resolveEntitlements` takes a structural `OrgRow` it declares itself; lint gate at `--max-warnings=0` proves no `@/generated/prisma*` import exists |
| T-02-05 | Denial of Service | Additive migration on a table with live rows | accept | Three nullable columns plus one defaulted column; `prisma migrate diff --exit-code` proves the applied state matches, and the two existing dev rows are intentionally left at `planTier = NULL` |
| T-02-SC | Tampering | npm/pip/cargo installs | mitigate | This phase installs zero packages (02-RESEARCH.md § Package Legitimacy Audit); any deviation requires a blocking human checkpoint before install |
</threat_model>
