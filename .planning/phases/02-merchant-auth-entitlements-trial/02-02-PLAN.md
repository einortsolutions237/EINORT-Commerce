## Phase Goal

**As a** merchant, **I want to** sign in to a dashboard that knows which store is mine from my session alone and shows my plan and trial state, **so that** I can run my store knowing my subscription limits are enforced on the server, not just displayed in the UI.

<objective>
Insert the mandatory plan-selection step between signup submission and the storefront redirect (D-01 through D-05), end to end: copy, screen, client island, and the `selectPlan` write.

Purpose: SUB-01 requires the three tiers to be a real, recorded choice on one codebase; ONB-05's 10-day trial is of the *selected* plan, so the selection has to exist and be persisted before anything can enforce it.
Output: `/onboarding/plan` renders three real pricing cards, a pick writes `planTier` + `planSelectedAt` to the merchant's own organization, and both post-signup redirect sites route through it.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `selectPlan` Server Action | Reachable by direct POST without the form; treat as a public API endpoint |
| browser → `/onboarding/plan` | An authenticated merchant can request the route in any state, including after abandoning the flow |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06 | Elevation of Privilege | `selectPlan` payload | mitigate | Schema is `{ tier }` only; the target organization comes from `session.session.activeOrganizationId`, and extra keys are stripped by Zod — proven by the forged-organizationId isolation test |
| T-02-07 | Spoofing | `selectPlan` called with no session | mitigate | `auth.api.getSession({ headers: await headers() })` is the only identity source; a missing session returns the existing session-expired result and performs no write |
| T-02-08 | Tampering | Price displayed on the plan screen | mitigate | Prices render server-side from `PLANS[tier].monthlyPriceXaf`; no price is ever accepted from or computed by the client, and no price literal exists in `strings.ts` |
| T-02-09 | Elevation of Privilege | Merchant abandons the flow and keeps `planTier = null` | mitigate | Selection is enforced server-side by the DAL's `planTier === null → /onboarding/plan` redirect (plan 02-03), not by the absence of a skip button |
| T-02-10 | Tampering | Third-party shadcn registry injecting code during `npx shadcn add badge` | mitigate | `components.json` declares `"registries": {}`; only the official registry is used and no registry entry may be added during this phase |
| T-02-SC | Tampering | npm/pip/cargo installs | mitigate | Zero packages installed; `npx shadcn add badge` copies source from the already-configured official registry, not a new dependency |
</threat_model>
